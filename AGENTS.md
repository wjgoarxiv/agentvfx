# agentvfx for coding agents

This repository is one agent skill: `skills/agentvfx/SKILL.md`. Read it before making a VFX clip, a visualizer, a stage loop or a live web effect.

- Run every engine command from `skills/agentvfx/` (paths inside a score resolve against the current directory).
- Requirements: Node.js 20+, Chrome or Chromium with GPU WebGL2, ffmpeg; Blender 5.x only for background plates.
- Check the machine first: `node scripts/vfx.mjs doctor`.
- Look at every render's stills and flash report before describing it to anyone.
